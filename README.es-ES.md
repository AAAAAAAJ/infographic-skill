## Cómo Usar Esta Skill (Generación de Imágenes de APIMart)

Primero, registre una cuenta en APIMart y obtenga su clave API:

https://apimart.ai/?sourceChannel=waytoagi

Después de iniciar sesión, cree una clave API y cópiela para su uso posterior.

Paso 2: Proporcione la Información de la API a OpenClaw
